# MyNissan

Веб-приложение для Nissan Leaf и Nissan Ariya: заряд, запас хода, состояние батареи, планирование поездок и журнал обслуживания. Проект для портфолио с демонстрационным режимом и интерфейсами подключения к автомобилю.

**[Открыть приложение](https://diana-troyanova.github.io/mynissan/)**

## Возможности

- Переключение между Leaf и Ariya, интерактивные 3D-модели автомобилей.
- Экран батареи: заряд, показатели состояния, ячейки и температура.
- История заряда и зарядных сессий.
- Расчёт поездки и сравнение автомобилей по заданным параметрам.
- Журнал обслуживания с сохранением записей и возможностью сделать копию.
- Настройки подключения адаптера и уведомлений.
- Манифест для установки приложения на главный экран.

## Технологии

**HTML · CSS · JavaScript · Three.js · WebGL · SVG · localStorage**

Основной интерфейс, стили и логика находятся в `index.html`. Three.js отображает модели в формате GLB, SVG используется для графиков. Настройки и локальные данные сохраняются в браузере. Сборщик и установка npm-зависимостей для просмотра не нужны.

Для подключения оборудования предусмотрены Web Bluetooth и Web Serial. Их доступность зависит от браузера, устройства и адаптера. Service Worker обрабатывает push-уведомления, но не кэширует страницы для автономной работы.

## Демо и подключение к автомобилю

Для знакомства с интерфейсом автомобиль и адаптер не нужны: без подключения доступен демонстрационный режим. Его показатели не являются реальными измерениями автомобиля.

Получение реальных данных требует совместимого адаптера и настройки подключения напрямую либо через мостик ESP32. Серверные маршруты `api/…`, к которым обращается приложение, не предоставляются GitHub Pages; код серверной части и прошивка мостика в этот репозиторий не входят. Наличие интерфейса подключения не подтверждает совместимость со всеми комплектациями Leaf и Ariya.

## Локальный запуск

Скачайте или клонируйте репозиторий, откройте терминал в его папке и запустите сервер с помощью Python 3:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для остановки сервера нажмите `Ctrl+C`.

Для загрузки внешних библиотек и шрифтов требуется интернет. Возможности подключения оборудования и уведомлений проверяются отдельно в поддерживаемом браузере.

## Структура проекта

```text
index.html             Интерфейс, стили и логика приложения
sw.js                  Обработка push-уведомлений
manifest.webmanifest   Параметры установки веб-приложения
leaf.glb, ariya.glb     3D-модели
leaf.webp, ariya.webp   Изображения автомобилей
icon-*.png             Иконки приложения
```

## Что посмотреть при знакомстве с проектом

1. Переключение между автомобилями и вращение 3D-модели.
2. Разделы батареи, истории и планирования поездки.
3. Создание записи в журнале и её сохранение после перезагрузки страницы.
4. Адаптацию интерфейса к экрану телефона.

Проект развивается. Проверка интерфейса в демо и проверка работы с реальным автомобилем — отдельные этапы.
