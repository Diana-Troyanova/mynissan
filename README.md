# MyNissan

Приложение для Nissan Leaf и Nissan Ariya: заряд, запас хода, батарея, поездки, журнал обслуживания.
Открыть: https://diana-troyanova.github.io/mynissan/

Без мостика ESP32 приложение работает в демо-режиме.
